# 진행 상태와 재현 근거

새 첨부 `CrossWeave_Work(2).zip`의 문서 8개를 SHA256SUMS와 대조했다.
기존 작업 파일과 Git 이력을 폐기하고 부모 없는 새 루트 커밋부터 시작한다.
현재 범위는 순열·역순열과 초기 공격 검사까지이며 AEAD C 구현은 후속 작업이다.

| 완료 항목 | 근거와 한계 |
|---|---|
| 연구 범위·보안 목표·상태·오라클 비용 모델 | 현재 명세·보안 문서, 안전성 미입증 |
| 입력·오류·Nonce 조건 | 공개 크기 헤더 C11 구문 확인, 첫 블록 복구식 기록 |
| AEAD 프레이밍·패딩·도메인 | 전이 그래프·가역 인코딩 논증, 실제 AEAD 상태 충돌 분석 미실시 |
| 프레이밍 자동 검사 | `python3 tests/framing.py`: 작은 알파벳 전수·경계·단계 구분·악성 프레임 |
| 선행 구성 비교 | NIST Ascon·duplex 원문 대조, 보안 정리 이전과 완전 동치 판정은 미해결 |
| 정확한 순열·역순열·상수 규칙 | 이웃 레인 누락 보완 명시, 단계별 전단사성 논증 |
| C11 LE·회전 유틸 | `make check`, ASan/UBSan; 비정렬·0/64/UINT_MAX 포함 |
| 공개 순열 인터페이스 | C/C++ 헤더 구문 확인, NULL·범위·0라운드 계약 정의 |
| 공개 상수·SHAKE 부품 검사 | NIST 빈 입력 KAT, 독립 Keccak와 hashlib의 흡수/출력 경계·32개 상수·IV 대조 |
| 짝수 레인 갱신 | 별도 수식 oracle의 고정 중간 벡터 12개와 involution 대조 |

로컬 환경에서는 LeakSanitizer의 `/proc` 접근이 차단되어
`ASAN_OPTIONS=detect_leaks=0 make sanitize`로 실행한다. 주소/UB 검사는 유지하며
누수 검사를 통과했다는 뜻은 아니다. 현재 순열은 동적 할당을 사용하지 않는다.

문서 변경은 인계 수식과 대조하고 `git diff --check`로 검사한다.
